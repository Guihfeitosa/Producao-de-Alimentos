SOBRE O PROJETO

Produção de Alimentos é uma iniciativa educacional open-source desenvolvida para unir pesquisa acadêmica rigorosa a uma experiência de interface luxuosa e imersiva. O objetivo é engajar estudantes através do design de alto nível.
